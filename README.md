# Projeto-NotebookLM-DIO

**Tema**
Análise de gráficos e estudos sobre investimentos de curto e longo prazo.

**Objetivo:**

Criar um cérebro que tenha o conhecimento de investidores famosos, juntamente com técnicas de investimos day trade, swing trade e estudos de mercado com analise de gráficos para tomadas de decisão a respeito de uma ação.
